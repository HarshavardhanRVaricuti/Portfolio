Built and benchmarked text classification models (LinearSVC, Naive Bayes, KNN, 1D CNN, TextCNN) to categorize news articles. Implemented TF-IDF vectorization pipelines to optimize feature extraction, identifying LinearSVC as the top performer.

I experimented end-to-end on a news article corpus: text cleaning, tokenization, building reproducible train and validation splits, and fair comparison across classical and deep learning baselines. Classical models on TF-IDF features provided a strong, efficient baseline, while PyTorch implementations of 1D CNN and TextCNN explored what additional signal learned representations could capture.

Across the benchmarks I ran, LinearSVC paired with TF-IDF remained the standout for this setup—a practical reminder that simple linear models on well-tuned sparse features are often hard to beat before investing in heavier neural pipelines.

Building a Live Financial Data Ecosystem with the Modern Data Stack

End-to-end data engineering for the financial data lifecycle: a custom Python extractor moves data from APIs to AWS S3 and Snowflake. Apache Airflow orchestrates the schedule; dbt runs SQL transformations; a Power BI dashboard uses DirectQuery so insights update as soon as Snowflake does.

I recently completed an end-to-end Data Engineering project designed to handle the entire lifecycle of financial data. Starting with a custom Python extractor, I built a pipeline that moves data from APIs to AWS S3, then into Snowflake for high-performance warehousing.

The “brain” of the project is Apache Airflow, which ensures the data flows on a schedule, while dbt handles the heavy lifting of SQL transformations to keep the data clean and structured. To close the loop, I built a Power BI dashboard using DirectQuery—meaning as soon as the data is transformed in Snowflake, the dashboard updates automatically.
